# Awesome Highlighting and Annotation

A list of research, tools, export and import projects, and formats for highlighting, annotating and taking notes while reading.

> **Disclosure:** this list was drafted by an AI assistant (Claude) from public pages fetched on 2026-11-09. No human has checked the entries yet.

Every entry links to a public page or record that loaded when the list was written. Research entries link to doi.org; their title, authors and year were compared with the Europe PMC record (and, for two, the publisher page). Descriptions use the page's own wording where possible. Entries are not ranked, and inclusion is not a recommendation.

## Research

- [Test-enhanced learning: taking memory tests improves long-term retention](https://doi.org/10.1111/j.1467-9280.2006.01693.x) - Roediger, Karpicke (2006). Compares retention after repeated study with retention after testing on prose passages.
- [To read or not to read: a meta-analysis of print exposure from infancy to early adulthood](https://doi.org/10.1037/a0021890) - Mol, Bus (2011). Combines studies on how much people read and its link to language and reading skills.
- [Improving Students' Learning With Effective Learning Techniques: Promising Directions From Cognitive and Educational Psychology](https://doi.org/10.1177/1529100612453266) - Dunlosky, Rawson, Marsh, Nathan, Willingham (2013). Reviews ten study techniques, including highlighting and rereading, and rates the evidence for each.
- [How to Make a Young Child Smarter: Evidence From the Database of Raising Intelligence](https://doi.org/10.1177/1745691612462585) - Protzko, Aronson, Blair (2013). Meta-analysis of trials, including interactive reading to young children, that tested effects on intelligence scores.
- [The pen is mightier than the keyboard: advantages of longhand over laptop note taking](https://doi.org/10.1177/0956797614524581) - Mueller, Oppenheimer (2014). Compares learning outcomes for students who took notes by hand and on laptops.
- [Cognitive effects and correlates of reading fiction: Two preregistered multilevel meta-analyses](https://doi.org/10.1037/xge0001583) - Wimmer, Currie, Friend, Wittwer, Ferguson (2024). Combines correlational and experimental studies of reading fiction and cognitive outcomes.
- [Highlighting and Its Relation to Distributed Study and Students' Metacognitive Beliefs](https://doi.org/10.1007/s10648-014-9277-z) - Yue, Storm, Kornell, Bjork (2015). Examines how students highlight, how it relates to spaced study, and what students believe about it.
- [Inducing Self-Explanation: a Meta-Analysis](https://doi.org/10.1007/s10648-018-9434-x) - Bisra, Liu, Nesbit, Salimi, Winne (2018). Combines studies in which learners were prompted to explain material to themselves.

## Highlighting and annotation tools

- [Glasp](https://glasp.co/?utm_source=github&utm_medium=awesome-list&utm_campaign=awesome-highlighting) - Highlights web pages and web-hosted PDFs from browser extensions (Chrome, Safari, Firefox, Edge, Brave, Opera) and iOS and Android apps; exports to Markdown, Notion, Obsidian, Roam and Zotero.
- [Hypothesis](https://web.hypothes.is/) - Social annotation platform for highlighting and commenting on web pages and other online content, with LMS integration; its web annotation client is open source (2-Clause BSD).
- [Hypothesis client](https://github.com/hypothesis/client) - The open-source Hypothesis web annotation client, released under the 2-Clause BSD License.
- [LiquidText](https://www.liquidtext.net/) - Document reading and annotation app for PDFs that runs on iPadOS, Windows 10 and macOS; proprietary.
- [Okular](https://okular.kde.org/) - Document viewer with an annotation mode for PDFs; also opens comics and EPUB books; free software under GPLv2+.
- [Readwise Reader](https://docs.readwise.io/reader/docs) - Reading app for articles, newsletters, EPUBs and PDFs with highlighting and notes that sync to Readwise.
- [Skim](https://skim-app.sourceforge.io/) - PDF reader and note-taker for macOS, designed for reading and annotating scientific papers.
- [web-highlighter](https://github.com/alienzhou/web-highlighter) - Dependency-free JavaScript library for highlighting and persisting text on any website; MIT license.
- [Xournal++](https://xournalpp.github.io/) - Open-source, cross-platform (macOS, Windows, Linux) handwriting note-taking software with pen, highlighter and eraser tools.
- [Zotero Reader](https://github.com/zotero/reader) - PDF, EPUB and HTML reader and annotator used by Zotero; the source is on GitHub.

## Exporting and importing highlights and notes

- [annotation-tools](https://github.com/collignon/annotation-tools) - Python tools that export Hypothesis annotations to Markdown files for Obsidian, using hypexport.
- [Fyodor](https://github.com/rc2dev/fyodor) - Converts Kindle highlights, notes and bookmarks from `My Clippings.txt` into one Markdown file per book; GPL-3.0.
- [hypexport](https://github.com/karlicoss/hypexport) - Exports a personal Hypothesis account's annotations and profile information; MIT.
- [kindle-clippings](https://github.com/lxyu/kindle-clippings) - Python script that extracts clippings from a Kindle `My Clippings.txt` file, organizes them and writes them out in a more readable form.
- [kindle-highlight-parser](https://github.com/honza/kindle-highlight-parser) - Parses the Kindle `My Clippings.txt` file and outputs JSON, Markdown or org-mode; GPL-3.0.
- [kindle-md-highlights](https://github.com/ratoru/kindle-md-highlights) - Script that converts Kindle highlights from `My Clippings.txt` into one Markdown file per book; MIT.
- [kindleHTML-to-markdown](https://github.com/AB1908/kindleHTML-to-markdown) - Converts the HTML notes exported from the Kindle mobile app into Markdown; GPL-3.0.
- [klip](https://github.com/alex-schaaf/klip) - Extracts Kindle clippings and sorts them by author and book title into folders and Markdown files.
- [Logseq Zotero Local plugin](https://github.com/benjypng/logseq-zoterolocal-plugin) - Logseq plugin that connects locally to Zotero 7 and above and pulls items into Logseq without Zotero Cloud sync; MIT.
- [noted](https://github.com/codito/noted) - Extracts annotations and highlights from documents such as PDF and from ebook readers such as Kindle and KOReader into Markdown; MIT.
- [Obsidian Importer](https://github.com/obsidianmd/obsidian-importer) - Obsidian plugin that converts data from Apple Notes, OneNote, Evernote, Notion, Google Keep and other formats into Markdown files; MIT.
- [Obsidian Kindle Plugin](https://github.com/hadynz/obsidian-kindle-plugin) - Obsidian plugin that syncs Kindle notes and highlights into an Obsidian vault; MIT.
- [Obsidian Zotero Integration](https://github.com/mgmeyers/obsidian-zotero-integration) - Obsidian plugin that inserts and imports citations, bibliographies, notes and PDF annotations from Zotero into Obsidian; GPL-3.0.
- [Readwise Official plugin for Obsidian](https://github.com/readwiseio/obsidian-readwise) - Obsidian plugin published by Readwise that brings a Readwise library into an Obsidian vault; GPL-3.0.
- [Zotero2Readwise](https://github.com/e-alizadeh/Zotero2Readwise) - Python library that retrieves annotations and notes from Zotero and uploads them to Readwise; MIT.

## Formats and standards

- [Web Annotation Data Model](https://www.w3.org/TR/annotation-model/) - Abstract data model for annotations as a relationship between a body and a target, serialized as JSON-LD; W3C Recommendation, 23 February 2017.
- [Web Annotation Vocabulary](https://www.w3.org/TR/annotation-vocab/) - RDF vocabulary and JSON-LD context terms used by the Web Annotation Data Model; W3C Recommendation, 23 February 2017.
- [Web Annotation Protocol](https://www.w3.org/TR/annotation-protocol/) - HTTP-based protocol for creating, updating, deleting and retrieving annotations and annotation containers; W3C Recommendation, 23 February 2017.
- [Selectors and States](https://www.w3.org/TR/selectors-states/) - Defines selectors (text quote, text position, CSS, XPath, fragment and others) for identifying a segment of a resource; W3C Recommendation, 23 February 2017.
- [JSON-LD 1.1](https://www.w3.org/TR/json-ld11/) - JSON-based syntax for serializing linked data, used by the Web Annotation serialization; W3C Recommendation, 16 July 2020.
- [EPUB Canonical Fragment Identifiers 1.1](https://idpf.org/epub/linking/cfi/) - Fragment identifier scheme for pointing to a location or range inside an EPUB publication; "Recommended Specification" dated 5 January 2017.
- [Readium Locators](https://readium.org/architecture/models/locators/) - Locator model for storing and sharing a precise position in a publication, covering bookmarks, highlights and annotations.
- [Hypothesis API v1 reference](https://h.readthedocs.io/en/latest/api-reference/v1/) - HTTP API reference for creating, searching and reading annotations; the API description labels v1 "Stable".
- [CSL-JSON schema (Citation Style Language schemas)](https://github.com/citation-style-language/schema) - JSON schema for the CSL-JSON data model used to store bibliographic metadata for citation processors.
- [OPML 2.0 specification](http://opml.org/spec2.opml) - XML format for outlines, used to exchange hierarchical lists.
- [The BibTeX Format](https://www.bibtex.org/Format/) - Explainer of BibTeX entry types, required and optional fields, and syntax; unofficial reference page.
